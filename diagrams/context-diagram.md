\# C4 Level 1 – Context Diagram



\## BFS and DFS Graph Search System



\### System Purpose



The BFS and DFS Graph Search System is a graph search system

that performs Breadth First Search (BFS) and Depth First Search (DFS).



The user provides the graph, starting node, and goal node.

The system performs the selected search algorithm and produces

the search result.



\### Context



User

↓

BFS and DFS Graph Search System

↓

Search Result



\### External Actor



\*\*User\*\*

\- Provides graph information.

\- Provides the starting node.

\- Provides the goal node.

\- Selects BFS or DFS.

\- Views the search result.
